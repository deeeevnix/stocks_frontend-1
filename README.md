## О проекте

«Запасы» помогает просматривать домашние продукты, находить нужные позиции и следить за их статусами. Этот репозиторий содержит основной экран приложения с карточками, статистикой и инструментами работы со списком.

Интерфейс оформлен в светлых розовых тонах по макетам Figma. В текущей версии используются шесть демонстрационных продуктов, заданных в HTML. Категории и статусы также заданы вручную. Удаление действует в пределах открытой страницы, после перезагрузки исходные данные восстанавливаются.

## Возможности

- Карточки с названием, количеством, единицей измерения, местом хранения, сроком годности и статусом.
- Поиск по названию без учёта регистра.
- Совместная фильтрация по статусу, категории и месту хранения.
- Сортировка по русскому алфавиту и сроку годности. Продукты без даты располагаются в конце сортировки по сроку.
- Статистика всех запасов и отдельный счётчик результатов поиска.
- Удаление карточки через окно подтверждения с обновлением статистики.
- Состояния «Пока пусто» и «Ничего не найдено».

## Запуск

1. Склонируйте репозиторий или скачайте его через **Code → Download ZIP** и распакуйте архив.

   ```bash
   git clone https://github.com/deeeevnix/stocks_frontend-1.git
   ```

2. Откройте `index.html` в современном браузере.

Текущая версия запускается напрямую из файла. Установка зависимостей и сборка не требуются.

## Проверка

После каждого сценария можно обновить страницу, чтобы восстановить исходные карточки.

| Действие | Ожидаемый результат |
| --- | --- |
| Ввести `мол` при сброшенных фильтрах | Остаётся молоко, счётчик `1 из 6` |
| Выбрать «Холодильник» и «Годен» | Остаётся молоко |
| Выбрать «Молочные продукты» при сброшенных остальных фильтрах | Остаются молоко и йогурт |
| Ввести `банан` | Появляется «Ничего не найдено» |
| Отсортировать по сроку годности | Хлеб первым, соль последней |
| Подтвердить удаление хлеба | Всего продуктов `5`, просроченных `0` |
| Удалить все карточки | Появляется «Пока пусто» и кнопка добавления |
